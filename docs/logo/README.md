## Files
- symbol-light / symbol-dark / symbol-mono-black / symbol-mono-white — 64x64 vector, no text
- app-icon-light / app-icon-dark — 1024x1024, squircle radius 232 (22.6%)
- lockup-light / lockup-dark — symbol + name, text as live <text> (needs Outfit installed; convert to outlines before handing to print)
- png/ — rasterized app icons at 1024, 512, 192, 64, 32

Clear space: min = height of the lower rack (9 units at 64) on all sides.
Minimum symbol size: 20px. Below that drop the light secondary rack for contrast.
